### [Simple CPU Emulator](https://github.com/moramarcomg/simple-cpu-emulator)
An 8-bit CPU emulator written in C++17, built from scratch — from raw registers to a working assembler with debug support.

- Custom instruction set: `MOV`, `ADD`, `SUB`, `JMP`, `JZ`, `JNZ`, and more
- Full fetch-decode-execute cycle with 8 general-purpose registers and 256 bytes of RAM
- Two-pass text assembler: write `.asm` files instead of raw bytecode
- Step-by-step debug mode for inspecting CPU state at each instruction

`C++17` `Systems Programming` `Computer Architecture` `Assembly`
